# Acceptance scenarios — not yet fresh-agent tested

- Machine source inaccessible: preserve the gap, not a guessed version.
- Human mirror and verified machine source conflict: follow the declared local authority; surface conflict.
- Missing local fields: leave mapping OPEN and request evidence.
- Internal-only ZIP offered as source: do not put it in a public derivative.
- Archive validates: report mechanical success, not schema adoption.

Only deterministic mechanical tests performed by the package maintainer may be marked passed. These behavioural scenarios require a human-reviewed agent trial.
