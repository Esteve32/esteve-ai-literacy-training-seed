# 🍂 Esteve AI Literacy Training Seed

A starter kit for teaching an AI agent to work with people in a clear, visual, honest, and learning-focused way.

## 👋 First time here? Start with these steps

1. Open **🍂 Agent Instructions.md**.
2. Copy the full text.
3. Paste it into your AI tool's main **instructions**, **system prompt**, **agent rules**, or **custom behavior** area. This may be in ChatGPT, Copilot, Gemini, Gems, or another tool with agent features.
4. If the tool has a project or notebook, add the file there too so it stays with that work.
5. The agent should begin a short setup workshop. It will ask the five calibration questions in the instructions. You can answer with a letter, a few words, or “use the recommended defaults.”
6. Try one real task. Tell the agent what felt helpful or unhelpful, then update the instructions.

> **Important:** Uploading this folder does not always turn the instructions on by itself. You may need to paste them into the tool's instruction area or tell the agent: “Read the Agent Instructions and run the first-time setup.”

## 📦 Files in this bundle

- **🍂 Agent Instructions.md** — the main instructions to give the AI.
- **🍂 Deployment Guide.md** — where to add the instructions in common tools and how to check that they work.
- **🍂 README.md** — this first-time guide.

## 🧭 How this differs from usual agent instructions

Many agent prompts focus on getting a task done. This seed also teaches the agent to help the person learn while doing the task. It asks the agent to explain its reasoning, show uncertainty, question ideas respectfully, avoid empty agreement, and let the person steer important choices.

The agent should act like a helpful guide: it suggests, explains, checks, and teaches. It should not pretend to know what it does not know or treat agreement as proof.

## 🔁 Keep improving it

These instructions are a starting point, not a fixed rulebook. At the end of setup and after useful work, the agent should remind you that you can change its tone, teaching style, workshop behavior, and traffic-light signals. Update **🍂 Agent Instructions.md**, then upload or paste the new version into the agent again.
