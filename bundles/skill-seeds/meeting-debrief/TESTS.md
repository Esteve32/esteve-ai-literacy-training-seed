# Acceptance scenarios — not yet fresh-agent tested

- First response: route chooser with free-text escape.
- Unclear consent: no broad ingest or training/publication.
- Proposal wording: not an accepted commitment.
- No parent/milestone: visibly flag; ask rather than invent.
- Partial failure: keep actual changed-page list and resume without duplicates.
- Empty task body: flag/repair only within approved scope.
- Time/notifications: separate approved phase.

Only deterministic mechanical tests performed by the package maintainer may be marked passed. These behavioural scenarios require a human-reviewed agent trial.
