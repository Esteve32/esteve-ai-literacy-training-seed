# Decode and rewrite a message consciously

Read COMMON.md and the bundled AI Literacy behaviour source. In a generated single-prompt export both are included. Apply them to the bounded task, not to unrelated accounts or settings.

## Inputs

Obtain source message, sender/recipient roles, relationship/stakes, must-keep wording/facts, mode (colour-code / rewrite / both / review only), desired length/tone, authorised signature if needed and destination. Ask for missing material context rather than guess identity or commitments.

## Procedure

1. Confirm mode. Use British English without translating direct quotes unless asked. Preserve all source facts, dates, amounts, uncertainty and the sender's agency.
2. Classify clause function, not sentiment. Green concerns the receiver's perspective/needs or genuine open curiosity; Blue conveys the speaker's self, facts, context, opinions, story, gratitude or apology; Red concerns asks, proposals, agreements, decisions or commitments. Gratitude/apology are not Green merely because warm. For multi-speaker material anchor to the current speaker.
3. If rewriting is requested, offer clearer, warmer, shorter consent-aware wording, explicit asks and surfaced assumptions. Never invent promises, deadlines, approvals or emotional knowledge. For decision-impacting content invite advice from affected people and those with expertise.
4. If rendering/stats are requested, use gbr-render-stats and its deterministic contract. The 75/20/5 mix is an optional training comparator, not a compulsory ideal. If detailed lens codes are requested, use jedi-orchestration's rights/mapping gate.
5. Show source-preserving decode rationale, optional proposed rewrite, unknowns and one fenced copy-ready message. Include only the user's authorised signature; do not copy a source individual's signature.
6. Keep review-only in chat. Show exact page/draft destination and preview before writes. Sending requires a separate explicit request and the active mail tool's confirmation rules. An inaccessible parent does not permit a standalone fallback without consent.

## Outputs

Provide selected mode, key, unchanged annotated source when requested, optional stats/reference, explanation and rewrite only when requested. Never force a rewrite into colour-code-only output. Record authorised writes in the local audit destination if available, otherwise report the gap. No mail accounts or address book are installed.
