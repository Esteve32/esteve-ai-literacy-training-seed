# Jedi communication orchestration — reference scaffold

Read COMMON.md and the bundled AI Literacy behaviour source. In a generated single-prompt export both are included. Apply them to the bounded task, not to unrelated accounts or settings.

## Inputs

Obtain message/transcript text, speaker labels, context/stakes, requested mode (decode / rewrite / both / review only), explicitly authorised reference material, destination and owner. Ask only material missing questions.

## Procedure

1. Clarify mode and whether the task requires lens names or verified element codes. Offer review-only by default where permissions or references are missing.
2. Use named lenses as reflection prompts: Influence; Attitude; Chaordic; Flow; Alignment and empathy; Needs; Ego; Dynamics. This is an orchestration scaffold, not the full GreenBlueRed™ Periodic Table or a validated assessment.
3. Require a permission-cleared reference and a verified name/code mapping for detailed element-level decoding. The source contains competing Flow/Alignment numeric mappings; do not assign L4/L5 or resolve that conflict silently. Keep original codes only when the supplied reference verifies them.
4. Interpret each clause from the current speaker's perspective. Green is genuinely other-focused curiosity/empathy; Blue conveys the speaker's self/facts/context; Red concerns shared requests, decisions, agreements or commitments. Do not colour globally by person or by warmth alone.
5. Separate observable words from hypotheses about intentions. Text alone does not establish non-verbal behaviour, emotion, intent or cultural traits. Never infer hidden mental states or apply unvalidated profiling/weights to people.
6. Delegate the requested transformation to email-decode-rewrite and mechanical rendering/counting to gbr-render-stats, using one evidence handoff rather than duplicate logs.
7. Preview the result and proposed destination. Write only after explicit scope approval, retain source quotes and uncertainty, read back and record local audit evidence if authorised.

## Outputs and refusals

Return the chosen mode, source facts, clause-level decode rationale, optional rewrite, reference/version/gaps, optional rendering stats and one copy-ready message. For review-only keep all output in chat. Stop for missing source, consent risk, unavailable rights-cleared references or ambiguous numeric codes. Do not represent this as the full Periodic Table extraction.
