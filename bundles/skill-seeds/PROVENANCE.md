# Provenance and release boundary

These seeds are reviewed adaptations of ten owner-selected sources from an organisational skill registry, authorised for public-safe prototyping. This is not a raw registry dump. The knowledge-kit source is a field guide, not itself a native executable Skill; it becomes an explicit scaffold here. Original source pages were not modified.

| Seed | Source version/context | Adaptation boundary |
| --- | --- | --- |
| Jedi orchestration | 11.37, legacy v0.1 reference/orchestration source | Named-lens workflow only; full restricted GreenBlueRed™ prompt/reference pack, case material, assessment data and numerical code mapping omitted pending rights/authority review |
| GBR render/stats | source v1.0 | Deterministic Unicode-code-point counting made explicit; comparator described as training reference, not validated quality ideal |
| Workstream template | portable v0.2, PR #1 | Reused unchanged; no second implementation |
| Portable knowledge kit | SEED human field-guide source, internal snapshot boundary | Generic authority/glossary/local-map scaffold, not full SEED schema/export; no internal archive, operational records or media |
| Create skill seed | source template v3.0 | Generic structure; no universal domain scores, zero-computation rule, fabricated citations or legal-basis claim |
| Brand core | current Arbora v3.0 text | Explicit illustrative brand; no logo/media/fonts or deprecated historical styles |
| Email decode/rewrite | source v1.0 | Local signature/destination mappings; no copied sender identity; no silent destination fallback |
| Project setup | source Skill 6.14 | Local templates/numbering/date-rule mapping; no database IDs or automatic calendar writes |
| Meeting debrief | source Skill 21.01 | Consent-aware small batches/resume; no transcript content or participant data |
| Source to microlearning | source Skill 10.01 | Adopting-team connection, optional mapped assets and human review |

Source/body hashes for reproducibility are in provenance.json; the private source/page-ID map is retained outside the repository. Public files contain no internal source URLs/IDs. Source status badges were not inherited as acceptance. All fresh-agent and human visual/behavioural checks remain pending.

GreenBlueRed™ is named for attribution, not as a licence grant or an assertion of assessment validity. No repository LICENSE was present at the inspected base. Technical validation and permission to open a prototype PR do not settle onward-use terms, logo/font rights, security review or rights to omitted reference materials. Confirm those before wider redistribution/release. No private originals or internal ZIPs are made public by this PR.
