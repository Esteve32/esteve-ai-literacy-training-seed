# Acceptance scenarios — not yet fresh-agent tested

- Unreadable URL: request content, not invented extraction.
- Source caveat: preserve it rather than make a stronger claim.
- Microlearning only: no prompt/task/library/audit side effects.
- Reviewer unknown: no prefilled real person.
- Full harvest: separate mapped records and exact write gate.
- No go: complete draft in chat only.

Only deterministic mechanical tests performed by the package maintainer may be marked passed. These behavioural scenarios require a human-reviewed agent trial.
