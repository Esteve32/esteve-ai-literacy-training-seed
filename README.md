# 🍂 Esteve AI Literacy Training Seed

A growing, practical training space for people who want AI agents to be visual, honest, clear, and good at helping humans learn.

## Start here

**New learner?** Use the [connection-free learning journey](bundles/learning-journey/README.md) first: extract one ZIP, upload/paste `START-HERE.txt`, then activate the dialogue. It needs no connected accounts. The original general-purpose setup remains below.

1. Open [the first-use README](bundles/🍂%20Esteve%20AI%20Literacy%20Training%20Seed/🍂%20README.md).
2. Copy [🍂 Agent Instructions.md](bundles/🍂%20Esteve%20AI%20Literacy%20Training%20Seed/🍂%20Agent%20Instructions.md) into your AI tool's instructions, system prompt, agent rules, or notebook settings.
3. Ask the agent to read that file and run the five-question setup workshop.
4. Use [🍂 Deployment Guide.md](bundles/🍂%20Esteve%20AI%20Literacy%20Training%20Seed/🍂%20Deployment%20Guide.md) for platform tips.

## Why this is different

Typical agent instructions mainly describe what the AI should do. This training seed also teaches the AI how to work *with* a person: explain its rationale, show uncertainty, question ideas respectfully, avoid automatic agreement, and teach through real tasks.

## Growing this repository

Add future training packs under `bundles/`. Give each pack its own README, core instructions, and deployment notes. Keep personal details, passwords, private keys, and access tokens out of the repository.

The repository name uses plain ASCII because GitHub repository names do not allow emoji characters. The 🍂 title and visual identity are kept in the README and bundle filenames.
