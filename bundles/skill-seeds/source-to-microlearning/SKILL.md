# Turn one source into action learning

Read COMMON.md and the bundled AI Literacy behaviour source. In a generated single-prompt export both are included. Apply them to the bounded task, not to unrelated accounts or settings.

## Inputs and route

Obtain one source URL/content, audience, learning goal, allowed facts/quotes, desired output route (Microlearning only / Prompt too / Full harvest / Preview only), target locations and human reviewer. If a URL cannot be read, request the content and mark the source gap; do not fabricate an article or transcript.

## Draft

Put the source link near the top; open with the bottom line, then 3–5 key points and 3–5 small actions. Keep prose scannable with one idea per bullet, examples where grounded and British English. Target a 2–5 minute activity, but label read time as an estimate, not measured attention. Distinguish source claims from interpretation and preserve critical caveats.

Add a one-question collective-learning feedback loop with a one- or two-column feedback table. Do not prefill real reviewers without confirmation or store identifiable feedback publicly without permission. Replace “Arbora connection” with the adopting team's relevant purpose/connection; do not assume Forest teams.

If a reusable prompt is requested, create a separately reviewable template through create-skill-seed, with clear inputs/output and safety gates. If full harvest is selected, propose locally mapped source-library, learning, registry, task and audit entries with source links; do not install databases or duplicate records. Choice of route is not blanket permission for all writes.

## Approval and output

Return the complete draft first, source/assumption gaps, desired outputs and an exact write preview. Wait for go for those destinations and records. Write small changes, read back and report actual output links, skipped items and resume/recovery notes. Explain does not automatically create a learning record or task.
