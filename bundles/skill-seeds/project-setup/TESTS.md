# Acceptance scenarios — not yet fresh-agent tested

- Missing milestone date: block that milestone creation and ask.
- Positive/negative offset: before/after only after local rule confirmation.
- Parent cycle/orphan: reject plan before writes.
- Missing template/schema: keep draft.
- Gantt native-date exception: surface separate effect before approval.
- Partial batch failure: resume verified unfinished items only.

Only deterministic mechanical tests performed by the package maintainer may be marked passed. These behavioural scenarios require a human-reviewed agent trial.
